# BÀI 02 - HỆ THỐNG QUẢN LÝ PHƯƠNG TIỆN

Bài tập thực hành lập trình OOP bằng C#.

## Các lớp chính

- PhuongTien
- OTo
- XeMay
- QuanLyPhuongTien

## Nội dung

Chương trình áp dụng 4 tính chất của OOP:
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism

Chương trình hỗ trợ:
- Thêm phương tiện
- Hiển thị danh sách phương tiện
- Tính giá lăn bánh
- Tìm phương tiện có giá lăn bánh cao nhất
- Tìm kiếm phương tiện theo tên hãng
